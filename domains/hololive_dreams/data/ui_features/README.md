# 独立状态特征资产

manifest.json记录27个特征的文件、搜索区域、来源截图、裁剪框和来源SHA256（含通知标题、礼物文字、成就页面、刮奖券入口及点击刮开文字）。每个特征有独立PNG；世界HUD/按钮、礼物及刮奖券入口文字另有foreground.png和mask.png。运行时只读取本目录资产，不再从完整归档截图现场裁剪。

成就详情使用顶部Rank标签与右下全部领取文字组合，列表使用左上成就标题；这些只识别页面，不代表按钮启用。按钮另外要求蓝底+白字，详情领取还需启用的单项领取证据；启动恢复只Esc，不用右下盲点代替返回。

tools/build_ui_features.py从归档证据重建。前景图提取白色/黄色UI，蒙版覆盖前景及窄边界；匹配用带蒙版的归一化平方差，避免大片亮背景只因亮度一致取得高相关分。限定按钮布局附近搜索，尺度容差保留。

世界证据组合：顶部至少三个位置一致的图标，加左下相机或右下跳跃按钮；原文字证据仍可独立补充。偏离行的单个匹配不再使所有证据无效。对话、奖励、选项等覆盖层始终优先；不把背景HUD直接当自由状态。

验证包含用户亮/暗背景两张图、缩放和亮度扰动、不同场景，以及菜单、奖励、任务、成就、小游戏页面反例。阈值为经验值，不等于概率；极端UI变化仍可能unknown。
