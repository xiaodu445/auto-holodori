# 演奏HUD参考来源

`rhythm_hud_reference.jpg` 原样复制自本地已有 `D:/Code/Codex/rhythm_detection_check.jpg`。
它是此前四帧打歌识别诊断拼图，不是本轮实机截图。本轮未修改原图。
运行时只取左上632×356帧中的SCORE/LIFE标题和底部六键键位徽标；不取音符、分数、角色或红色诊断框。
用途是加载结束后确认演奏界面，无音符也可放行引擎的all-held基础持键。
相关测试覆盖擦除中间音符区仍能识别、16张菜单/加载/奖励原图均不通过此门控。
当前参考对应已有固定轨道布局，多人不同HUD布局和动画仍需真实样本验证；未知界面不凭加载结束直接放行输入。
