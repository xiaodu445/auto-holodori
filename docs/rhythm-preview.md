# 音游识别预览

双击run_rhythm_live_preview.cmd，5秒内切回游戏，关闭游戏内AUTO并开始简单谱面。
run_rhythm_preview.cmd只观察，不发送键盘输入。F12停止，关闭预览也会停止。

黄框：检测到的蓝色横条。灰线：六轨边界。红线：配置中的判定线。
橙色标签：跟踪编号、映射键和剩余毫秒；WAIT SPEED表示还没有稳定速度。
绿色CONSUMED：程序已消耗此音符事件，可能已发送或已过期，不表示游戏命中。
底部显示LIVE/DRY RUN、实际循环FPS、检测数、按键状态和各阶段耗时。
inhibited=stale frame表示当前帧耗时超过50ms，输入被抑制。

复用现有非激活原生预览窗口，独立线程最多20Hz，只显示最新帧。若屏幕右侧
空间不足，预览可能放在游戏左侧；需安排窗口位置，避免遮挡谱面。
此版本用于定位现有识别问题，仅处理蓝色短音符，其他颜色暂不发送动作。
