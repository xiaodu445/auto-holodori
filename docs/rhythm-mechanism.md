# 连续减速机关实验

试用入口 `run_rhythm_mechanism_test.cmd`；只记录计划而不改变按键用 `run_rhythm_mechanism_shadow.cmd`。
原有稳定入口不变。F8开始/暂停、F10录制、F12退出；沿用当前参数、默认不限时。

当前实验明确将已学习的脉冲解释为八分音符，3个十六分间隔=脉冲×1.5。
触发需要多颗蓝键给出连续多帧减速趋势，并已有至少四颗可靠宽蓝条及音乐脉冲时钟。
瞬间停住、阶跃变速、速度噪声或证据不足不触发这条策略。

只重排已识别的连续宽蓝条，不凭空补键，不把同样间隔强加给后段散键。
由于小节起点仍有歧义，当前采用最多16颗/4秒的有界过渡队列，尚未自动实现下一小节确定进入。
实际录像重放中间隔为187.38ms，但这不是实机命中验证；使用F10录制后可在分析页查看机关状态、事件及紫色计划点。
本模式不能与global-flow active同时使用；入口选择global-flow shadow，避免两种策略反复覆盖预测。
