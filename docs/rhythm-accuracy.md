# 2026-10-19 粉色重复键修复

## 红区硬隔离与长按中段预测

识别掩码现直接截止prediction_zone[1]（默认0.54），所有颜色都不识别红区，
触碰裁剪边缘的不完整横条丢弃；不会再从底部同色区域续接或换轨。
长按记录中段拖尾路线，用同一空间相位模型安排换轨；无尾判，已知路线结束
后保留最后键，直到新同轨音符需要重按或20秒安全上限。新同轨头之前先松开，
默认8ms目标释放间隔（实际间隔受输入耗时和调度影响）；相邻同色音符不会因
长按存在而被吞掉。
未知跨屏后续曲线不能靠此完整还原，变速/巨长滑条仍待专项样本。
旧实际运行报告是历史证据，不会被悄悄改成新算法；重新录制才能看新运行结果。

默认仍为中段预测；箭头不是单独音符，粉色只跟踪横条。颜色横条切成的薄片
不再单独建轨迹；不是靠全局延后输入或忽略所有相近音符来掩盖重复问题。

最新录像前三颗粉色横条的离线按键7→3(K/D/K)，其他颜色次数未变。
运行原run_rhythm_live_preview.cmd即可使用；F12/失焦保护保持不变。

蓝色实验没有证明加长拟合窗口更准确，因此保留既有曲线与8点窗口。
近端校准near_blue_refinement缺省false；用户要求暂不处理变速/底部识别，
本轮回放与默认实机路径均未启用该可选实验功能。

这是AUTO录像离线模拟，不含实机按键延迟，也不是Perfect率测试。
粉色实际按法、输入偏移、游戏内部判定时钟仍需实机反馈。
