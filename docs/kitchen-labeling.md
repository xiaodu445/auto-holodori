# 厨房实例点标注

双击 kitchen_label.cmd，默认打开最新录像。可用 --recording 指定其他录制目录。

## 操作

1. 从顶部选择类别。左侧参考图来自本次录像，仅供辨认；暂名类别需要核对语义。
2. 单击物品可见部分内部的可靠点击位置。一件物体只标一次，多件同类分别标点。
3. 看不清类别或分不清实例时，选择“忽略区域”，拖框覆盖不确定部分。
4. 选中右侧列表条目可删除；撤销支持当前帧的标签修改。
5. 完整标出容器内所有可辨认实例、框出不确定区域后，勾选“本帧已完整标注”。
6. 用前后帧、前后10秒或时间轴切换。每次改动立即保存，重新打开自动载入。
7. 导出已完成帧，得到PNG与manifest.json，供后续点热力图训练。

类别添加：两个输入框分别填写稳定英文ID和中文名，再点添加。不删除/重排已有ID。
现有类别表 data/kitchen/classes.json；参考裁图 data/kitchen/references/。
默认容器ROI针对当前录像；可在annotations.json中编辑roi（归一化[l,t,r,b]）后重开。

## 标签约定

每帧拥有独立instance_id、class_id、点击点x/y、ignore_regions与complete标记。
坐标使用完整视频像素（不是屏幕坐标，不是裁剪后的坐标）。ROI保存在根级元数据。
每个物体只能一个点；点应远离遮挡边缘，不要求位于完整物体中心。
同一物体露出多片区域仍只标一个点；动画/弹窗帧不要标记完成。
ignore_regions内训练时须屏蔽负样本损失；当前工具只保存标签，训练代码尚未实现。
任何标签变更都会取消complete，防止旧的完整性确认沿用。
空场景可确认完成，但应只选稳定游戏画面，不以弹窗/结算充当背景。

标注位置：录制目录/point-labels/annotations.json，原始录制不改动。
导出位置：录制目录/point-labels/dataset/manifest.json；训练以清单为准，
旧导出的PNG可能保留在目录中，不得用扫描PNG目录代替manifest。
PNG从有损MJPG视频解码，不会恢复已损失的细节。
数据集按独立对局分组拆分；当前一局只做流程与拟合检查，不报告泛化精度。
类别图谱是人工视觉建议，不代表标注实例已确认，更不代表游戏真实命中。

首批建议挑10–20张差异明显的画面；不需要逐帧标注5396张。
此入口不发送游戏输入、不启动训练；训练器下一步接入。

首批AI人工视觉标注保存在录制目录/point-labels/assistant-annotations.json，启动时自动补入尚不存在的帧。已有窗口需关闭后重开。保存合并其他帧的外部改动；同一帧冲突会另存conflict副本并报错，不覆盖远端。

## 自行从新录像挑帧

kitchen_select_frames.cmd自动打开最新录像，用对应独立manual-labeling目录。
拖动时间轴松开可看当前帧，点击“加入当前帧”加入队列；重复加入不重复，移出只改队列、不删除已有标签。
默认仅浏览选帧，点击画面不会误加实例点；用户可手动切换实例点/补框模式进行标注。
队列自动保存selection.json；重新打开自动载入。新录像不自动加入任何后台训练。
原有kitchen_label.cmd仍指向旧12帧，两个入口互不覆盖。


## 缩放、切换录像和模型菜单建议（2026-10-22）

从 kitchen_select_frames.cmd 打开，顶部可放大/缩小/适应窗口，放大后使用滚动条。点和拖框坐标按画布滚动与缩放反算原图坐标。
“选择录像”支持本项目录制的 screen.avi，必须保留旁边的 timestamps.json；切换前保存，标签固定在 runtime/kitchen/manual-labeling/<录像目录名>/annotations.json。编辑或保存时，将原帧保存到该目录 frames/frame-<帧号>.png；同一帧不重复创建图像。
“预测当前帧 / 排列类别”在独立CPU进程加载最近完成的模型，将当前帧各类最大检测置信度用于菜单排序；全部人工类别仍保留，当前选择不变，不自动写入点或框。未检测出的类别排在后面，没有预测结果的新增类别仍可选择。百分数不是校准后的类别存在概率。
预测记录在同一录像标注目录 predictions/，换帧后旧预测不会应用到当前帧。当前训练不受菜单预测影响。
