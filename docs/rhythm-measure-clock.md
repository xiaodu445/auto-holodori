# 小节时钟旁路实验

入口：项目根目录 `run_rhythm_measure_shadow.cmd`。沿用当前调参，F8开始/暂停、F10录制、F12退出；默认不限时。

只观察，不补键、不改变当前按键期限。全局流速为shadow，不启用active速度重排。
F10录制后正常退出，分析页右侧新增“小节时钟（旁路）”、脉冲间隔、原节奏间隔及下一小节候选。
旧录像没有这些新记录，需要新录制。`--measure-clock off`可关闭；其他入口默认不启用。

从稳定区可靠蓝键的到达估计学习独立时钟；和弦合为同一时间事件。异常流速出现后，已锁时钟继续计拍，但冻结视觉训练。
没有锁定时钟时，异常后暂缓2秒学习。记录只在本首运行内维护，不建立长期曲库。

四拍小节、脉冲为八分/十六分均为假设。保留两种解释和多个起点；匀速连打本身不能证明强拍。
长间隔后的进入、和弦分布只作弱排序依据，最高启发式置信度65%，不视为音乐专业分析或确定答案。
密集音符不会直接把已锁脉冲时钟翻倍；不合当前网格的新增事件记录冲突，暂不自动细分网格或换拍号。

本版不执行“连打到下一小节”，也不自动为未知音符补数量。先检查变速前是否获得足够可靠时钟，以及小节候选能否覆盖实际进入点。
