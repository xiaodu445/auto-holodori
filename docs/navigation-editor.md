# 宝藏刷新点与路线标注工具

## 跳跃记忆、半惯导对照与路线示教

自动路线运行时，可在障碍处手动按Space。程序只监听游戏前台的真实Space按下边沿，过滤SendInput等注入事件和长按重复；用按下前后的可靠位置插值记点，同时保存地图、路线几何/名称、动作段和行进方向（位移不足时用镜头方向）。预览紫色圆圈与JUMP MEMORY数量表示已保存。位置/镜头未确认、切换路线段或样本间隔>0.5秒时不保存，并在运行日志说明。程序自动发送的Space不会再学习。

下一次执行同一地图、同一条路线，到记忆点6地图像素内、同动作段、朝向差<=30度且没有明显越过点位时，自动W+Space一次。一次尝试后本轮不重试；本轮手动新学的点不立即自动再跳。记忆不是已确认的跨墙连接，不会据此改变A*禁行区，也不证明跳跃落地成功。空格仅0.12秒触发，之后仍靠定位确认进展；真正跨禁行区的跳跃仍需已有定向连接标注。

运行模式下拉框提供：

- **小地图（同时记录预测误差）**：默认。小地图有效时直接采用，另行记录已发送W时长、鼠标计数形成的逐帧预测与从起点累计的纯输入位置。
- **融合（巡航短暂丢帧预测）**：小地图有效仍直接采用，只在已开始巡航时补齐最多0.25秒的位置/朝向缺失；不以预测启动新移动，不将预测当成镜头响应证据，记忆跳跃点12像素附近先制动等视觉。原完整场景0.5秒、F12、失焦/遮挡保护不变。

“查看最近运行对照”显示同项目最近10次运行的模式、路线、单步预测平均偏差、纯输入累计终点偏差及停止原因。先对照同一路线；这些是与小地图的一致性指标，不是物理真值或成功率。输入模型暂按经验稳定速度28.5像素/秒和实测鼠标比例积分，没有精确补偿起步加速、松键滑行、碰撞和人工鼠标操作，所以会真实显示漂移。

**示教与复走：** 先选择并规划当前路线，点击“示教记录（手动走）”，8秒内切回游戏。你自己走动/转向/跳跃，程序记录可靠小地图轨迹及真实Space，完全不创建输入控制器。F12或关闭预览结束保存。随后选同一路线，点击“复走示教（自动）”，按录下的空间轨迹走，继续用当前定位校正，并将示教跳跃点重新绑定到轨迹段；不按原始按键时长盲放。

示教轨迹仅作1.5像素容差的折线压缩，不因为掩膜看似可走就抄近道。中断的定位、太短的录制另存candidate，不覆盖已有有效示教；跨未知/禁行区的轨迹拒绝复走，需先补标注。地图/路线变动后记忆隔离，原地图/路线/标定文件不改。记录存于`runtime/patrol/route-memory/`，每次运行的summary包含实际文件路径；CLI可用`--experience-root`另选目录。

CLI：普通自动路线可加`--estimator fused`；手动示教用原preview参数加`--teach-route`并去掉`--live-route`；复走用`--live-route --replay-demo`。示教与自动路线共享互斥锁，不能同时运行。当前完成离线和模拟回归，Windows监听器启动/消息泵/关闭已做无目标测试，无输入发送；游戏内真实Space学习与自动复跳、融合改善程度仍待实机验证。

## 绕障规划与路线跟随辅助

在“巡逻路线”页标好途经点后，先画可走区/禁行区，再点击“按可走区绕障规划”。默认4px网格/2px安全边距，可调整。只有人工可走区且有底图覆盖的位置参与搜索；禁行优先，安全边距会收缩通道。端点靠墙、区域不连通、未标通道时明确报错，不画一条假路线跨过去。

绿色为规划步行路线。可选择“规划可使用已验证的定向跳跃”：先在标注列表选中跳跃，勾“该跳跃已手动验证”并应用；只沿起跳→落点方向连接，端点也需在可走区。紫色跳跃仍需人工操作。规划后的标注修改会使旧规划失效，需要重新规划。

导出额外包含planned-route.json、planning-mask.png、planned-route.png及配套patrol-config.json。地图指纹和标注签名用于拒绝过期规划。原人工route.json仍保留，规划文件与人工草稿分开。

“定位 + 路线跟随辅助预览”启动独立位置追踪，8秒内切回游戏，显示当前目标和途经进度。你手动走路线；接近目标后推进。跳跃处提示手动处理，连续两帧定位在落点后继续。它不发送移动/拾取/跳跃输入。无运动标定时只提示目标；传入已测WASD标定时可生成最多0.12秒的移动建议，仍为影子建议。每次建议需要新鲜定位、自由场景和在可走掩膜内的线段，取消后停止；未将坐标到达等同宝藏已拾取。

当前辅助按一遍路线推进；闭环路线为一圈，结束后不自动无限重复。反转跳跃会清除已验证标记，需要重新确认反向可行。

命令行被动预览：`patrol.cmd preview --fast-track --config "导出目录/patrol-config.json" --planned-route "导出目录/planned-route.json"`。

## 自动行走与跳跃

当前采用“优先走、途中纠偏”：方向差在30度内且可走掩膜的前视检查通过，就可开始持续W；行走中45度以内继续小步转镜头，每次新定位重新计算，不要求一开始完全对准。巡航纠偏2400计数/秒、每次最多360计数、每步最多24；原地粗转仍7200计数/秒。上一段转向尚未显示完、单帧小幅反向或估角方法变化不会直接按“转向故障”退出。走廊不允许、角差过大时先制动重新朝向，接近目标仍精细靠近。旧逐命令转角确认已从当前LIVE移除，未知方向、定位长期失效、持续卡住、弹层、失焦/F12等仍会停止。新策略已做离线回归，实机行走速度与成功率待验证。

自由场景与“可跳跃”分开识别：跳跃时按钮缩小、Space标签放大有独立模板；无跳跃按钮时（例如用户描述的下海状态），依靠小地图边框和其他稳定HUD确认是否仍在自由世界，不单因按钮消失退出。此时不记录/触发记忆跳跃；路线中的明确跳跃动作不可用会以具体原因停止。灰色按钮、已知弹层、失焦、遮挡等仍会抑制输入。按压态真实截图已离线验证，水下目前仅用移除按钮的模拟画面测试，尚待水下实景核对；这项更新覆盖路线/示教，不自动替换旧独立建图器的门控。

当前自动执行统一采用W前进和鼠标转镜头，不发送A/S/D，也不再进行四向探测。要单独测W和镜头，可点击“W加速 / 镜头一圈标定工具”，见[标定说明](motion-probe.md)。

1. 标好可走区、墙体禁行区和有向跳跃。跳跃连接必须人工验证，再勾选规划允许跳跃，点击“按可走区绕障规划”。旧导出需要重新规划以保存跳跃验证字段。
2. 角色站在规划可走区，点击“仅W + 转镜头自动行走 / 跳跃”，8秒内切回游戏。自动加载最新完整连续镜头标定，不需要再次按四方向。窗口尺寸应与标定时一致，运行中不要手动操作鼠标。可走标注需要符合游戏实际，程序不知道未标出的墙和高度。
3. 程序比较小地图与底图的暖色变化，结合双帧两条边界拟合光锥中线，两帧确认视觉可靠性；不拿人物突起当镜头。如果光锥不明，停稳后小幅转镜头收集差分，最多8秒，无可靠方向就停止。预览橙箭头显示镜头方向，粗转7200计数/秒后观察校正，巡航微调2400计数/秒；新鲜方向用于下一轮纠偏，不再对单次转动做符号/幅度硬失败确认。
4. 当前LIVE采用连续W巡航：对准目标后跨帧保持W，每次定位更新同时小幅转镜头纠偏；不再每一帧松键停稳。按剩余距离、28.5地图像素/秒、6像素经验滑行和识别耗时计算本次允许继续前进的时间，接近目标逐渐缩短，再制动精细靠近。路线急拐、跳跃起点和终点先制动；近点短按仍最多0.30秒并等待位置稳定，到点仍需两帧确认。新鲜定位/镜头丢失即松键，不能拿键盘累计位移代替定位。

   连续输入由独立100Hz线程维护，W只按下一次；巡航鼠标微调2400计数/秒、单步<=24计数，修正角度超过45度先制动。原地大转向按剩余角差/实测计数比例计算85%粗转量，单段最多120度，以7200计数/秒、单步<=128计数快速发送，再截图精调。新速率的物理响应未重新标定，计数估计用于初步控制，再依据新视觉修正。每次批准最多到原截图捕获后0.5秒；主线程识别、日志或预览阻塞也会到期松键，期限不足则等下一帧。OS焦点/遮挡/窗口/F12仍逐步检查，弹层/禁用由主线程完整场景识别；到期不是证明场景安全。原地转向留出检查开销，实际提前结束时记录已发送计数；未实机验证新连续模式。

   光锥识别排除人物突起，用底图暖色差分和静止双帧的两条有符号移动边界互补，半角固定46度；单边/无变化不猜转角。鼠标实际计数预测只排除不合理估角，不能替代有效视觉。切换估角来源先重观测，不再直接当转向异常退出。预览显示中线、两边线及来源/置信度，观察日志包含各候选角和计数预测。小范围短时序扫描仍可能歧义，未知时先停走。
5. 已验证跳跃先对准落点，W+Space一次，之后只用W纠偏、不在空中转镜头，2秒内落点位置连续两帧才继续；失败不补跳。没有物理落地传感器，地图落点不等同可靠着地。当前路线只执行一遍；F12、失焦、遮挡、窗口改变、预览关闭均结束；定位失效超过2秒、移动后5秒无进展、当前途经点60秒超时均退出。

每次启动导出独立地图/路线快照，界面启动的运行日志、末帧截图和标定保存在该导出目录的 `run` 子目录；命令行默认使用新的 `runtime/patrol/时间戳` 目录。程序结束后编辑器显示停止原因和诊断目录，原地图和标注不改。窗口标题标明LIVE；原来的辅助预览仍不发送按键。此功能不自动按E拾取。

命令行自动执行：`patrol.cmd preview --fast-track --config "导出目录/patrol-config.json" --planned-route "导出目录/planned-route.json" --live-route --fps 10 --start-delay 8`。可用`--camera-calibration "camera-calibration.json"`指定已完成的连续转向标定；`--forward-speed 28.5 --stop-distance 6`调整经验初值。旧`--auto-calibrate`仅兼容参数，不再发送四方向探测；旧WASD控制器保留作离线回归，不接当前LIVE入口。

已做离线闭环模拟、输入故障/取消、跳跃超时、灰色HUD、场景遮挡语义回归；完整游戏路线和不同跳跃高度尚未实机验证。自动执行使用自由HUD及已知弹层识别，未知且保留HUD的弹层仍可能漏检，不能宣称通用场景感知。

双击项目根目录 `navigation_editor.cmd`。编辑标注本身离线；游戏预览和自动执行由各自按钮显式启动。默认使用最新完成的修复地图；同一底图已建项目时恢复最近一次项目。首次为空白标注，地图随机彩点不自动当作宝藏刷新点。

## 先标宝藏，再整理路线

1. 默认“宝藏点”模式：在地图点击添加；点击已有点选中。右侧可改名称、备注及刷新间隔（未知留空）。点位是可能刷新位置，不表示当前有宝藏。
2. 右侧“巡逻路线”页点击“全部宝藏追加到路线”，按标注顺序加入。也可在“点位/区域”页选择点后点“选中点加入路线”。支持多条命名路线和闭环。
3. 切换“路线拐点/选点”：点击已有点加入当前路线，点空白处插入绕行拐点。路线清单可上下调整、移出、反转。移出路线不删除点位；同一点可在路线不同位置重复经过。
4. “建议顺序”只按直线距离做最近邻排列，固定第一个点，可撤销；不保证最短路、可通行或避障。下方报告显示长度（地图像素）以及禁行/未知/底图缺口警告。按实际行走添加拐点。

## 地形与跳跃

- “可走区多边形”“墙体/禁行区”：逐点点击，Enter或完成按钮结束，Esc取消未完成草稿。禁行区优先于可走区。细墙也可用窄多边形表示。
- “定向跳跃”：先点起跳位置，再点落点。只存该方向；反向需要另加连接或在列表选中后“反转跳跃方向”。备注可写台阶、楼层和操作要求，默认未实机验证。
- “选择/拖动点”可移动宝藏或拐点；区域/跳跃在右侧列表选中后可重命名、备注、删除或撤销。此版不提供区域顶点拖动。
- 跳跃连接独立保存，只有已验证且规划选入的有向连接能自动执行。可走区/禁行掩膜不把地图已观测覆盖等同于可通行。

## 画布与保存

默认100%地图原始像素，窗口变形不拉伸地图。滚动条/滚轮移动视口，右键拖动画布；Ctrl+滚轮或顶部±等比缩放，100%按钮还原。标注坐标始终是原图像素。

修改后约0.5秒自动保存，Ctrl+S立即保存（包含正在编辑的属性），Ctrl+Z撤销最近60步。关闭前保存失败会保留窗口；未完成多边形草稿需先完成才入项目。Delete在路线清单中只移出当前步骤，文字框中照常编辑文字；地图/标注列表中删除所选标注，删除点位会同步移除各路线引用，可撤销。

项目位于 `runtime/patrol/navigation/时间戳-编号/project.json`，其中的map.png是独立底图快照，地图指纹和尺寸会核验。项目目录可整体备份；原修复图及其他配置不改动。底图几何变化时新建项目，旧项目继续使用其快照，不静默搬移旧坐标。

“导出路线/标注”每次生成独立exports/时间戳目录：

- `navigation.json`：全部点位、区域、定向跳跃、多路线和校验提示。
- `treasures.json`：全部宝藏刷新点及备注/已知刷新间隔。
- `routes.json`：所有路线的顺序、坐标、闭环和提示；`route.json`为当前路线，保留旧巡逻框架可读取的points数组。
- `annotations.png`：完整标注预览；`walk-mask.png`、`blocked-mask.png`为独立掩膜。
- `map.png`及覆盖图：导出底图快照。路线是待人工确认草稿，reviewed和navigation_verified不自动置为true。

打开已有项目：`navigation_editor.cmd --project "完整路径/project.json"`。指定其他地图配置：`navigation_editor.cmd --config "导出目录/patrol-config.json"`；“新建项目”也可选择地图配置文件，另存新目录。
