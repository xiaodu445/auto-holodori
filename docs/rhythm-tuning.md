# 音游调参入口

音符左右边界会在可靠时量化到12格离散轨道，中心在键位分界上固定归属，避免像素抖动重复建轨。
历史重复轨迹合并同时要求同色、同格范围和相近运动/到达时间；同帧出现过的两颗音符保留独立身份。此项不依赖节奏吸附参数。

右键项目根目录的 `run_rhythm_tuning.cmd`，选择编辑，修改顶部 `set` 数值，保存后双击运行。修改在下次启动生效。启动为待机、录制关闭；游戏前台按 F8 开始/暂停按键，F10 开始/停止录制，F12 退出。当前暂停也会暂停截图，录制只保存运行中的画面。

| 变量 | 默认 | 调节含义 |
| --- | --- | --- |
| RHYTHM_FPS | 120 | 处理目标上限，30–240；不代表截图有同样数量的新帧 |
| RHYTHM_WIDTH | 960 | 识别宽度，480–1600；降低可减少计算，小音符可能难识别 |
| RHYTHM_GRID_SNAP | 3 | 节奏网格最大吸附偏差，0–25ms；0关闭修正，仍收集节奏 |
| RHYTHM_OFFSET | 10 | 按下提前量，−100–100ms；正数越大越早按 |
| RHYTHM_RELEASE_LEAD | 60 | 在补偿后按下目标前提前松键，0–300ms；越大越早松 |
| RHYTHM_DENSE_GAP | 100 | 连续音符保护阈值，0–300ms；0关闭；10ms以内同组和弦不视为连续 |
| RHYTHM_DENSE_RECOVERY | 125 | 保护音符目标之后恢复长按的等待，25–500ms |
| RHYTHM_DENSE_TAP | 12 | 密集保护中的按住时间，1–50ms |
| RHYTHM_MIN_DOWN | 12 | 每次重按后，至少按住多久再允许松开，1–50ms；适用于目标键和密集模式 |
| RHYTHM_RELEASE_GAP | 8 | 相邻按下之间，至少松开多久，1–50ms；普通提前松键量不足此值时自动补足 |
| RHYTHM_KEY_LOOKAHEAD | 0 | 换列选键暂时关闭，统一按本列；设为100可恢复100ms前瞻选键 |
| RHYTHM_SLIDE_GUARD | 160 | 小键后方彩色滑块保护窗，0–500ms；0关闭此优先级 |
| RHYTHM_DURATION | 600 | 总时限，1–1800秒，包含暂停时间 |
| RHYTHM_RELEASE_SCOPE | target | target只松对应键；all启用全键松按实验 |

`OFFSET=10` 与 `RELEASE_LEAD=60` 表示预计判定前约70ms松键，前10ms按下。密集保护在锁定相关音符后释放覆盖键，不使用普通松键提前量。建议一次改一个值。

也支持命令行覆盖，例如 `run_rhythm_tuning.cmd --fps 120 --analysis-width 720 --release-lead-ms 80`。末尾参数优先。录制保存在 `runtime/rhythm/live-reviews/`。

网格修正示例：`run_rhythm_tuning.cmd --grid-snap-ms 8`；已知BPM可追加 `--bpm 240`。
只有网格锁定且视觉预测与最近网格点相差在阈值内时，才吸附到该点，最多修正指定毫秒。
调大意味着更多音符接受节奏修正，不改变整体早按/晚按补偿。有效上限另限制为基础网格间隔的49%，避免跨越半格边界。
默认3ms；例如改为8ms后，相差6ms会吸附，相差12ms仍沿用视觉预测。网格未锁定不修正，也不生成未识别音符。

快速序列采用每键独立计时：一次按下至少保留MIN_DOWN，再松开至少RELEASE_GAP。间隔太短或发现太晚时可能晚按，日志保留lateness_ms。
左右交替按用户确认的四格键盘范围，优先选能碰到当前音符、又碰不到下一时刻音符的键；再比较前瞻窗内其余冲突和距中心的距离。
例：视觉D列的音符允许S/D/F触发，而下一颗F列允许D/F/J触发时，第一颗优先用S。释放开始后固定该次选键，避免中途换键漏掉按下。
没有独占键时选择冲突最少的候选；无法承诺排除连带命中。无完整位置/宽度信息时保留原中心键。分析事件记录visual_lane、input_lane、input_conflicts。
候选键至少需要0.5个谱面格的有效交叠，边框轻微越界不算可触发。最右侧三格仅允许K/L，最左侧三格仅允许S/D。
两格小键（测量宽度最多2.5格）后方160ms内有绿/黄滑块时，即使中间有其他音符也优先使用本列键，例如J列小键保持按J。
该时间窗独立于普通KEY_LOOKAHEAD，可用SLIDE_GUARD或--slide-guard-ms调整，0关闭该优先级。10ms以内同组和弦不算后方滑块；已忽略尾端不参与。
宽条沿用普通前瞻选键；事件input_reason记录选择原因。KEY_LOOKAHEAD=0时直接使用本列，相当于关闭全部换键。
本优化用于target和密集模式；显式release_scope=all仍全键重按，无法利用独占键。按下及松开时间是调度时间，操作系统实际投递仍有开销。
