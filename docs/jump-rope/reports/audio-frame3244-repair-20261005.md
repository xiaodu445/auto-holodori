# 第3244帧错误低空诊断与修复

人工反馈：56.046352秒是圆周减速，不是左右摇。标注保存在 domains/hololive_dreams/data/jump_rope_samples/human/20261005-audio-frame3244.json。

## 两个根因

旧回放第3222帧（55.669844秒）凭低位视觉误入low_swing，commit_episode清掉全部圆周候选并记录一次低空经历。第3244帧只剩低空候选；减速声第56.364880秒才被尾窗识别，小幅音频加分找不到减速圆周候选。之后低空退出又套用必反向规则，造成错误方向。

阶段三减速还存在独立问题：旧模板速率0.76且status=pending_calibration，legal_successor拒绝选择。即使纠正低空入口，仍在正常/加速间漂移。

## 独立实验修复

新页 runtime/jump-rope/frame-review/audio-decelerate-repair/index.html；保留 audio-start-gated 和中间 audio-low-authorized 回放。

圆周进入低空前需近期专属左右摇语音授权：4秒内、距离≤0.22、类别差距≥0.04。其余音频仍用0.26/0.015宽门槛留候选；宽匹配不直接授权一次破坏性的模式提交。分支依旧须视觉支持和合法方向，语音不直接强制低空。掉落提示不提供运动授权。这是当前音画实验路线，若声音缺失可能漏进低空，不能声称视觉无音频场景同样可用。

本录像56–60秒正摇慢速独立测量0.5475圈/秒，已结合人工55.590–56.540秒减速提示绑定为阶段三正摇减速试验模板。保存 audio_forward_decelerate_trial.json，正摇时钟形状单独保存，原 stage_clock_library_v2_trial.json 不变。新设置 jump_rope_audio_decelerate_config.json。角色区间确认不是精确运动边界；仅同录像开发拟合，verified仍false。阶段三反摇减速及其他阶段减速没有因此完成独立标定。
