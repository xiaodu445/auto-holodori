# 可见绳段优先：微调与纠错两条路径（2026-10-06）

## 用户要求

持续可信的可见绳子，是相位与速度的第一依据。区分两套机制：预测基本正确时，以细微相位修正抑制累积误差；估计已经出错时，重新计算相位和速度，进行大幅纠错。

## 实现

主线使用 jump_rope_visible_fit_config.json。原候选评分仍使用原来的局部搜索表；独立纠错表每帧搜索全部旋转/低空相位，不对预测相位附近额外加分。完整图像证据计算一次，原局部表从中切片，避免重复识别。两张表分开使用，避免纠错搜索改变原候选评分的含义。

可信条件：图像质量至少0.65，可见覆盖至少50%，运动支持至少10%，至少14个绳子支持点，并且比相隔0.06或更多的竞争相位高至少0.06。场景突变和明显多解不可信。这些分数是当前特征置信度，不能当成人工标注真值。

| 路径 | 条件 | 动作 |
|---|---|---|
| gentle 微调 | 可信绳段且当前时钟误差不超过0.04圈 | 每帧只纠正误差的25%，同时受原每帧上限及本帧移动量30%限制；不直接跳到拟合相位 |
| recovery_pending 纠错确认中 | 相位误差超过0.04圈 | 收集至少5个可信观察、跨度至少0.12秒；检查方向、速度范围、运动连贯性和残差 |
| recovery 大幅纠错 | 大偏差通过独立窗口确认，或长窗口证明速度/档位明显错误 | 重新定位相位，或更新速度/档位，清理失效候选与旧速度证据 |

速度窗口取最近0.45秒：至少10个可信观察，跨度至少0.30秒。可信观察之间间隔超过80毫秒，或模式、有效阶段、技能代次变化，重新积累。独立绳段相位经各档自己的时钟形状转换后进行直线拟合；残差不超过0.010圈、可见位移至少0.08圈，才采用观测速率。

档位明确时更新档位。若速率可靠但名义档位过近或与未标定模板不符，只更新观测速率，保留档位且记录 gear_confirmed=false。这样旧模板速度不会否决持续可信画面，也不会伪造已确认档位。后续速度约束围绕最后可信观测值，避免小幅校正又把速度夹回错误模板。近期0.5秒内，声音及旧候选不能推翻可信速度；模式转换仍沿用原合法边界和音频辅助规则。

30圈规则保留：计数稳定确认时直接切换阶段3模板，之后可见速度证据优先纠正实际时钟。GPU调查保留，未增加GPU依赖。

## 验证与使用

590项测试通过，其中新增13项覆盖两条路径、大偏差等待连续确认、小幅修正上限、正反摇的独立速度拟合、短时遮挡、技能代次重置、相近档位不乱命名、观测速率优先于名义模板以及音频不能推翻近期可信速度。

实时预览显示 fit=gentle / recovery_pending / recovery，以及 speedFit。完整日志与逐帧页面的 visible_fragment_fit 给出采用路径、图像质量、相位误差、窗口、各档拟合残差和拒绝理由。双击 run_jump_rope.cmd 重新启动；open_jump_rope_frame_review.cmd 打开 runtime/jump-rope/frame-review/visible-priority-review/index.html。

同一段100个录像帧的单线程CPU识别抽测（首20帧不计）：旧策略平均22.95ms，新策略36.21ms。新增完整相位搜索有额外成本；这不是实机帧率测量，不包含捕获、声音、预览和键盘发送。详细数据：runtime/jump-rope/visible-priority-performance.json。

完整7529帧回放：2704帧可见片段达到严格可信条件，1580帧进行gentle微调，40帧进行recovery纠错；166帧采用独立可见速度。166是滑动窗口采用帧数，不是166次独立换挡。本录像没有达到无歧义档位重命名条件，因此这些速度更新记录 gear_confirmed=false；正反摇明确档位切换另外由合成时钟测试覆盖，仍需实机核对。

原有人工模式检阅点1405（低空）、2752（低空）、3244（阶段3减速）全部保持；3710为阶段3加速。3563变为阶段3正常，与旧版阶段3减速不同，不能宣称该点已经修好。该帧独立相位窗口残差0.091圈，被拒绝，仍等待连续证据；速度模板和角色标签仍有未标定部分。5758有效模板为阶段4正常，阶段5问题仍需另行策略处理。

抽看3244与5318的实际导出图片：前者保留减速曲线，后者可见绳段与大幅纠错后的曲线接近；抽看不代表全部帧几何准确。记录位于 runtime/jump-rope/frame-review/visible-priority-review/visible-fit-audit.json 和 regression-audit.json。旧 visible-fit-review、visible-dual-review 是中间试验，不作为当前入口。
