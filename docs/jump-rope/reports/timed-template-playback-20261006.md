# 整圈模板按时间播放：离线原型

用户明确的方案：数据库保存每种阶段、技能、方向的一圈绳形随时间变化；按各自周期播放候选，以持续可见绳段选择最匹配者。小差异调整播放时钟，大差异积累证据后重新对齐或切换。候选保留；遮挡期间继续播放。每圈按模循环，无须每圈依赖一次新的起点检测。

实现 `src/modular_agent/realtime/timed_rope_playback.py`。输入是可信可见绳形点；不从旧绳形库反推几何相位。候选有独立周期、阶段/技能/方向/镜头约束。只在已标注的空间范围与时间间隔内插值，未知绳段不参与评分。连续窗口0.45秒；搜索160个时间进度；误差与远相位竞争差不足时保留当前时钟。小偏差阈值0.04圈，修正25%、每次上限0.01圈；大修正至少4条观测且跨0.12秒。这些是离线原型参数，未实机标定。速度档位由候选自身周期提供；不把绳形导数当作档位速度。

首份模板来自2564–2641的22帧人工绳形，周期1.321591200秒；第二圈2641–2717用于检验。排除共有起点后15个内部标注帧，固定周期播放纵向RMSE为10.74像素（720图高换算、每帧等权、只计算有支持的人工标点）；按第二圈确定周期归一化为12.10像素。该数值不是完整画面识别准确率，也不能跨评分方法直接比较。无需重新拟合旧模板几何相位。

因果回放故意把起点延后120毫秒，路径为3次收集、1次恢复、12次微调。6项测试覆盖循环、未知区域、微调上限、大调整证据窗口、遮挡续推、候选择优保留与非单调时间。模板库109份JSON校验通过。

检阅页：runtime/jump-rope/frame-review/stage2-timed-playback/index.html，展示16帧第二圈原图、人工点与按已确认起点播放的曲线；控制器错起点试验独立记录在每帧文字及validation.json中，橙色曲线不是错起点控制器曲线。构建工具：tools/jump_rope/build_timed_playback_review.py。

限制：只有一个真实阶段2反摇正常模板，多候选切换仅模拟验证；镜头一致，同一录像的第二圈验证尚不是独立录制验证。标注点间插值不是完整可见/遮挡掩码，需继续检查形态；周期首尾实测绳形有小差异。当前输入是人工可信绳段，不是已接入实时的图像提取器。主线识别和空格控制尚未改动。后续将模板可见曲线直接送入现有图像评分，并在新旧方案并行回放验证后接入实时。
