# 左右摇前缀证据与边界候选保留

反馈来自 audio-decelerate-repair：第1405帧24.356682秒和第2752帧47.561807秒，用户确认应是左右摇。

原实现只用完整技能片段尾窗识别，首次低空提示分别24.844秒和48.204秒；临时音频门控未开放，尽管后者已有强低空视觉候选，仍保留无可见支持的圆周。前者的低空候选还在约24.27秒先过期，随后声音无法对不存在的分支提供支持。这是开关/保留策略问题，不是无论如何都应相信原圆周模板。

新声音判断每0.08秒比对模板前0.25/0.4/0.6秒，全部为因果尾窗：没有读取当前时刻之后的录音，也没有用人工标注时间安排切换。同录像模板存在训练同源偏差，不能声称独立泛化。前缀距离≤0.22、类别差距≥0.05作为临时证据，最多有效0.40秒；完整声音判断仍保留。音频仅授权候选竞争，最终仍要求视觉支持、合法分支和连续确认；掉落提示不授权运动。没有声学证据时不因此强制换低空，也不把0.40秒前缀当作已确定技能持续时间。

边界候选原保留0.9秒，延长到1.25秒，保留原路径播放等待前缀。此窗口也适用于其他边界候选，需逐帧审阅其影响；没有扩大任意时间/方向的转换合法性。先完成短语再确认的门槛不再作为唯一入口。

新设置 jump_rope_audio_prefix_config.json；新页 runtime/jump-rope/frame-review/audio-prefix-retained/index.html；原 audio-decelerate-repair、audio-prefix-review 回放保留。前者已校准的阶段三正摇减速模板保留，防止3244帧错误回归。

声音前缀实测：24.284秒左右摇距离约0.025、类间差约0.135；47.484秒左右摇约0.053/0.161。55.804–56.045秒主要识别为减速，不授权左右摇。均为本录像开发结果，未独立素材验证。

回放保留7529个源帧、一帧一图、阶段/模板/候选及完整/前缀声音诊断。可在audio_review.tentative_prefix查看临时候选；人工标注导出格式不变。复现 tools/jump_rope/replay_audio_review.py。


## 最终确认时序修复

保留窗口延长后，1405和2752帧已有明确低空候选，却仍差固定65毫秒确认窗口的约15毫秒。最终版本只在有效低空前缀距离≤0.10、类别差距≥0.08，且可见低空候选分数比活动圆周高0.10以上时，将确认缩短到35毫秒。其他场景仍65毫秒。最终页 audio-prefix-confirm/index.html，1405/2752均确认low_swing，3244仍确认正摇减速；仅三个标注关键状态已检查，全段仍待人工逐帧验收。

514项回归通过，之后导出器图像复用修改的6项相关测试通过。复用现有图片前先对整段预测时间、控制判断、覆盖曲线、相位参数、点状态和模板名逐帧核对一致，仅更新诊断数据，不复用不同轨迹的旧覆盖图。

完整音频片段及短前缀来自同录像，留出泛化还未完成。临时前缀可能误识别；片段不够清楚时会拒判。旧A/G默认控制保持不变。本轮仍不发送空格，不把图像无支持本身当作左右摇确证。
