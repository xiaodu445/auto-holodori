# C4 长时分析（2026-10-04）

约两小时离线开发，用已有4010帧录像，未实机输入。保留单低空档与遮挡重入修正；三个独立周期保存为校准数据。其他策略未整体优于基线，未替换A/C3。

## 跟错原因与证据

- 背景边缘及照明变化得到绳子分数。帧差可排除不变背景，但明暗变化使静态边缘也获得运动支持；改用几何边缘位移又漏掉慢、小位移绳子，试验整体更差。
- 搜索围绕模型阶段展开，所谓图像速度带有模型先验。用它证明当前档位会形成循环，新时钟测量链仍支持错误档，未改善整体。
- 小幅阶段回正可吸收部分速度误差，使错档短时间也贴图。加入档位增加相似候选，第一次慢摇误选快档后影响退出及方向。校正量惩罚有局部收益，但54.8/55秒仍不能及时退出。
- 首段黄色周期不能代表全程。三个独立周期2.399/2.005/1.710秒；中后段完整时序与接缝未独立校准，共用首段变换仍是待验证假说。
- 退出防重复原要求一整圈可见行程，在遮挡中停在0.848圈。新条件将持续播放周期和实际上半圈短行程结合，修复这处重入延迟。
- 人工抽样也会混淆：0.75秒步长像低空，0.1秒密抽显示74秒仍有完整上半圈。标签已更正，全部保存对照按当前标签重新计分。
