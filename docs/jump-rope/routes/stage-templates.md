# 分阶段四分支原型（2026-10-05）

这是独立只判断原型，尚未优于当前G，不替换原入口。启动 `run_jump_rope_stage_judgment.cmd`；F12、Ctrl+C、失焦停止。仍不发送空格，180秒会话时限保留。现有A自动、G圆周落地分支、C3和G基线均保留。

## 录像确认的阶段

对已有录像的计数和等级标志进行离线人工审查，得到如下分级；时间只用于验证该录像，实时不用这些秒数切级。

|阶段|计数范围|等级切换时间夹区间（秒）|圆周观测候选中心（圈/秒）|低空候选完整周期（秒）|
|---|---|---|---:|---:|
|1|0～9|初始|0.73|未测，按相邻阶段缩放|
|2|10～29|14.545～14.710|0.76|2.399|
|3|30～49|39.914～40.035|0.9475|2.005|
|4|50～69|60.307～60.447|1.07|1.710|
|5|70及以后|78.095～78.253|1.4325|未测，按相邻阶段缩放|

10次确实切等级。阶段2圆周样本只比阶段1略快，不能单凭等级切换宣称所有分支的具体增幅已测准。录像仅到第五级，后面是否继续升级未知。第3/4/5级对应不同背景，不以背景消失判成功。

50、70次升级都发生在已有低空片段中。因此阶段升级保留轨迹阶段、方向、进入方向和技能片段，整组速度同时缩放；不能清空轨迹或等低空退出再升级。旧速度证据和候选会被清除。

## 每级四分支

常态、加速、减速、左右摇为同一阶段内的四个行为；正转/反转是独立方向维度，不与难度阶段或加减速混成一组全局档位。落地后的圆周候选继续使用多帧比较和一次性接管；低空仍使用旧片段约束。

配置在 `domains/hololive_dreams/data/jump_rope_phase/stage_profiles_v1.json`，每级 `branches.normal/accelerate/decelerate/low_swing` 各有clock_rate和校准来源。只保留当前级的速度集；实际等级提示升级后整体替换，各角色速度共同提高。

**加速、减速没有独立标签样本。** 圆周窗口只是观测速度簇，不能证明它属于该级常态还是技能。现在常态暂用该级速度簇，加减速暂用相邻级已观测速度簇作候选先验，最外两项用旧挡位边界比例0.84/1.16。它们不是游戏实际倍率，也不是录像中已测出的技能周期。第1/5级低空按相邻测量缩放，同样未校准。全部verified=false。

先前统一乘1.25/0.8的试验导致32秒误差约145px，已放弃；相邻观测先验虽有所改善，仍约116px，不能取代G约7px。未来需要从同级实际加速、减速段独立拟合周期并标注类型，不能继续把跨级速度当成技能真值。

## 阶段提示与实时开销

同一速度可能是前级加速或后级常态，仅凭运动无法唯一确定级别。原型只在小块等级徽章ROI上每0.1秒检查色相直方图，不读生命、不逐帧OCR、不全屏匹配、不请求大模型。单次或模糊提示不升级，确认后不因短暂丢失回退等级；缺提示时保留现级。新会话/窗口尺寸变化重建组件后可重新初始化。

阶段徽章数据为 `stage_badges_v1.json`，来自五段稳定徽章窗口的直方图中位数，生成器 `analyze_jump_rope_stages.py`。等级识别在本录像确认时间为14.974、41.309、60.907、78.552秒；第3级因动画有约1.3秒延迟，尚需改进，不能宣称瞬间升级。

为了获得徽章，只有新原型横向扩大采集ROI到0.01～0.88；仍非全屏。原G的ROI和行为保持。固定绳形、运动、输入保护沿用组件接口。另有独立绳子ROI试验，状态精度反而变差，默认关闭 `separate_stage_roi`。

## 回放与保留结果

相邻先验版本：4010帧，1417接受观测，8次状态切换，9/11稀疏状态点；14/20/32/55秒曲线误差约4.13/5.76/115.75/12.60px。32秒仍跟错，54.8/55秒低空退出仍晚。接受帧数不是准确率。CV平均10.65ms、P95 13.17ms，不含采集、预览。只做离线，没有实机输入。

扩大ROI但内部另裁原绳区的对照：1216接受帧、7/11状态点，32秒仍错误低空，误差276px；未采纳。详见 `runtime/jump-rope/stage-analysis/` 中replay、neighbor-prior、separate-roi各自记录。早期配方未保存源码字节，重建文件会明确标注；后续验证器保存settings-used和两个素材JSON。

测试覆盖四角色各级升速、低空中升级的轨迹/方向/片段保留、旧速度证据清除、复位、非法阶段拒绝、低频提示、多样本确认、遮挡/模糊不升级和错误ROI拒绝。441测试通过，旧组件均通过。

## 再开发

运行说明：设置PYTHONPATH=src、PYTHONUTF8=1，使用项目的Python：

```text
.conda\python.exe -m modular_agent.realtime.analyze_jump_rope_stages
.conda\python.exe -m modular_agent.realtime.validate_jump_rope_phase --gear --gear-settings domains/hololive_dreams/models/jump_rope/jump_rope_stage_config.json --output-dir runtime/jump-rope/stage-analysis/recheck
```

纯数学在 `staged_trajectory_bank.py`；等级提示在 `stage_badge.py`；领域识别工厂通过stage_model开关选择，当前G配置未启用。优先补足每级三种圆周行为的独立速度标签和低空接缝，随后再评估升级提示延迟与实机仅判断效果。
