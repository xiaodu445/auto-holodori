# 固定轨迹三状态 v3

2026-10-04，独立实验C3。目的不是加状态标签，而是约束合法运动：正摇、反摇、有限范围的低空左右摇。现有C2/v2、C/v1、A自动路线的配置和入口保留，不更改默认自动路线。

## 2026-10-04 即时续推修正（当前代码）

用户补充：下落不会零速；只有上升减速才可能进入低空左右摇。原实现先让候选改速度/历史，再验证输出曲线，失败后只降低置信度；近零速还可等待0.65秒才恢复。这使错误观测能污染预测，并出现挂住。

当前将候选关联作为可撤销的试算。候选不能得到输出曲线支持、也没有连续移动的独立绳形证据时，恢复更新前的相位、速度、方向和观测历史，当帧立即用原状态推进，扩大搜索。寻找新候选与续推同时进行。连续移动候选允许修正平滑模型的位置/速度，但其支持不等于预测曲线已被看见。普通旋转零速必须等待低空模式确认，不写入当前旋转运动；预测曲线下落时近零候选被拒绝。上升减速仍保留为低空模式线索。低空转折的图像坐标可以短暂近零，角度先验继续推进；位置校正不得把已推进的预测抵消成完全停顿。

候选重获取允许连续证据确认相反方向，避免原方向续推后无法接回反向绳子。预览/状态输出增加continuation来源和association_rejection原因。prior_prediction表示撤销候选后沿原状态预测；visual表示接受候选关联，不代表整条曲线都有视觉支持。绿色点仍仅表示当前输出曲线的真实局部支持。

370项测试通过，包含首个丢失帧正反向精确续推、候选不能污染历史/速度、下落零速立即拒绝、低空遮挡/转折的连续预测。既有A/C1/C2路线未修改。修改前C3源码、配置、文档和结果保存在docs/jump-rope/history/state-v3-before-immediate-coast/，对应项目原相对路径。

连续性记录：763个未换状态/重获取的旋转续推帧均满足上一相位加原速度乘真实时间差，最大计算误差为0；本录像模型锁定后没有完全冻结的非零速段，也没有旋转近零速段。这是估计器行为检查，不是游戏真实状态的逐帧标注。

当前完整4010帧回放：视觉支持2302帧（修改前2537），14/20/32/55秒可见点中位误差约10.55/5.90/9.27/13.39像素。55秒比原约0.88像素退步，状态重获取仍有代价；持续推进不是准确性证明。下方原回放表及annotated.avi、validation-contact.jpg是修改前历史结果，当前结果看report.json、replay.json、immediate-coast-comparison.json和immediate-coast.avi。

识别平均12.72ms，P95为21.45ms，本次测试/回放有并行CPU负载。它不包含采集/预览，不能据此宣称实机满足60FPS；即时续推解决估计停滞，不消除计算/显示卡顿。蓝绳模板失配与遮挡重获取仍需继续改善，C3保持只判断，不替代自动路线。

## 运行

双击run_jump_rope_phase_state_judgment.cmd，或路线菜单按S。3秒准备后切回游戏，显示状态、坐标、带方向的速度、置信度、搜索范围和重获取次数；只判断，不发送空格。F12、Ctrl+C、切走停止；识别丢失继续尝试，默认180秒会话时限仍保留。

CLI为--phase-rope --phase-state。不能同时加--phase-reverse或任何真实输入/test-space标志。v2回退入口run_jump_rope_phase_reverse_judgment.cmd仍可直接运行。

## 合法运动与识别可信度分开

- 正摇/反摇仍沿原固定整圈路径，不逐帧重拟合曲线，不允许独立节点乱跳。
- 低空摇使用独立的有限路径，坐标0～1，禁止越界或把1绕回0。路径样本为约束二次曲线，插值仍是二次曲线，没有五次多项式的局部扭曲。
- 普通旋转的图像修正不能抵消预测推进。无可靠关联时当帧扩大搜索、降低置信度并续推；下落近零候选和未确认低空状态的旋转零速候选被拒绝，不等待零速超时。
- 低空转折允许短暂近零速；中段持续停顿不作为合法转折。图像丢失时用有限、平滑的摆动先验，推测端点转向，但不当作已观测。
- 搜索保留最多3个非邻近阶段候选。换支重获取需要连续候选、质量与方向证据；重获取时可能纠正到不同位置，记录事件，不把这一跳当作真实瞬时运动。

识别丢失、恢复、候选未确认是跟踪状态，不是第四种游戏运动状态。模型满足约束仍可能识别到背景，必须看绿色支持与置信度，不能用“三状态合法”代替准确性验证。

## 三状态确认

连续可靠绳形上升、估计速度逐渐降至近零，并且低空路径有足够视觉支持时，优先进入低空摇。只有突然零速或弱图像支持，不强行切换。

低空摇确认后允许在有限路径往返。进入前方向被保存，退出时以相反方向作为先验；需要连续的整圈路径/运动证据确认退出。若连续相位分支证据与先验矛盾，保留画面证据并记录出口先验，不能强制错误方向锁到背景上。这个冲突可能来自相位分支歧义或错误状态进入，仍需人工核对。

## 修改前零速时限与素材（历史）

用户确认只有低空转折可能短暂零速，不应长期停住。已有录像17.6～18.1、18.6～19.4、19.9～20.5、20.8～21.7秒的可见投影转折检查：在端点附近15/1000客户区高度的空间带内，采样跨度约0.11、0.50、单点、0.51秒。这个空间带停留时间不等于精确物理零速时间，含约0.1秒采样与曲线拟合误差。

实验zero_timeout设0.65秒（上述约0.51秒加采样余量），可在jump_rope_phase_state_config.json调整，尚非所有速度/技能的实测上限。中段零速超过0.12秒即拒绝作为可靠摆动观测；弱曲线支持超过0.12秒扩大搜索。普通旋转也只暂时容忍未确认的转折，不能一直以零速作为可靠运动。

原录像的一段已知黄色绳，用颜色筛选和约束二次RANSAC离线提取，生成8个有限路径样本。颜色筛选仅用于这段素材建模，实时仍用灰度细条、边缘、近期变化与运动。

素材：domains/hololive_dreams/data/jump_rope_phase/swing_recipe.json、swing_v1.json（verified=false）。采样约17.9～18.65秒、端点约19.0～19.31秒。参考完整摆动周期2.394秒来自两次可见前端附近采样时间差，作初始先验，实时速度仍会更新。此坐标按中心投影排序，但实时匹配整条41点曲线，不能称为只跟踪高度。单方向样本与遮挡外推有偏差，不是完整游戏真值。

build_jump_rope_swing_atlas.cmd可复现；训练核对图runtime/jump-rope/phase-state/swing-training-contact.jpg。14、20、32、55秒稀疏人工核对点没有参与新低空素材拟合，但仍在同一录像，非独立实机验证。

## 代码与产物

通用模型：src/modular_agent/realtime/motion_states.py，LegalSignedTracker、BoundedSwingTracker、BoundedTrajectory。v1/v2原PhaseTracker和SignedPhaseTracker未改。领域：jump_rope_phase_state.py，独立组合原视觉几何与评分，灰度边缘/距离图只算一次供两条路径共享；没有逐帧OCR、UIA、全屏匹配或大模型。

配置jump_rope_phase_state_config.json；ROI仍按游戏客户区归一化。换尺寸/移动/失焦由共用框架保护；改变纵横比或黑边仍需校准。此路线无需新依赖。

run_jump_rope_phase_state_validation.cmd完整回放，输出隔离在runtime/jump-rope/phase-state/：replay.json、report.json、annotated.avi、last-result.json、loss-roi.npz。v2基线存phase-reverse/，v1存phase/，不覆盖。主last-result.json与sessions仍按框架保存最近运行和会话。

注意low_swing中的rate为有限坐标/秒，旋转为圈/秒，不能混合比较数值或把参考周期当成固定按键间隔。当前没有起跳/落地/危险经过的v3控制器，也没有成功/失败/999计数验证，结果仍unknown。
