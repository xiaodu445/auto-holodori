# 轨迹与速度挡位 v4（C4，独立实验）

2026-10-04。保留A自动、C1/C2/C3入口、代码和配置，不替换默认自动路线。

## 运行

双击run_jump_rope_phase_gear_judgment.cmd，或路线菜单按G。CLI为--phase-rope --phase-gear --preview。仅判断，不发送空格，不能同时选C2/C3或加真实输入/test-space。F12、Ctrl+C、失焦停止；识别丢失继续播放运动假设，默认会话时限180秒。记录隔离在runtime/jump-rope/phase-gear/。

## 模型主体

预存rotation_v1整圈轨迹和swing_v1有限轨迹。整圈沿正向/反向播放；低空轨迹使用持续前进的角时钟转换为0～1往返坐标。模型时钟速率始终为正，方向另存。低空端点的画面投影速度可以瞬时为零，但角时钟没有停止。对q=(1-cos(2πθ))/2，速度为πf·sin(2πθ)，固定挡位内的轨迹加速度为2π²f²·cos(2πθ)。转折处速度零而加速度非零，下一帧自然反向。输出template_acceleration是模板计算值，不是图像实测加速度，也不包含速度微调产生的额外项。预览同时标出模型clock速度与投影速度，避免混淆。

当前临时旋转挡位中心0.40、0.55、0.75、1.00圈/秒；每挡允许±22%微调，最低0.312、最高1.22。低空挡位中心0.34、0.418、0.52个往返周期/秒。它们来自现有C2录像候选的连续11帧阶段拟合和低空素材参考周期，不是已确认的游戏内部挡位或真实极限。speed_calibration.verified=false，所有参数在jump_rope_phase_gear_config.json独立保存；不能用单份误识别录像宣称挡位已经实测准确。

不沿用C3的逐帧速度回归或零速超时恢复。无视觉支持时按最后模型/挡位直接推进；可信移动片段可在挡位范围内修正速度。阶段校正上限0.008周期且最多当帧推进量30%，不能取消推进或凭校正反转。

## 合法后继竞争

经过模板边界才生成保持、相邻快慢挡、低空模型或退出低空后的相反整圈方向。各候选沿自身轨迹推进，以后续画面的局部绳形、运动支持及阶段误差累计评分。明显领先且连续支持至少65ms时选中候选；单帧尖峰不换模型。保留当前候选，同时按状态、挡位、低空运动方向分组，最多24个假设，遮挡不把它们清空。

用户确认游戏在绳子脚下经过瞬间切换，最新规则优先于C3原“上升降速到零”启发式。本版旋转切换边界暂由模板中角色附近最低绳形估计；低空退出边界沿用与整圈脚下绳形最近的有限轨迹位置，尚未独立标定到游戏真实脚下时刻。低空轨迹接续位置由整圈边界与有限模板的最小曲线距离选择，当前素材可能无法完全衔接。这些是明确的校准缺口，不能称为三状态切换已经准确。

视觉只运行ROI内灰度边缘/细条/帧差及固定模板匹配，共享C3视觉特征实现，C3决策不参与。初始阶段仍需连续视觉候选建立定位；以后通过小校正与边界分支确认维持。没有生命/计数/结束识别，画面消失不判成功。

## 验证

run_jump_rope_phase_gear_validation.cmd离线回放现有录像，输出report.json、replay.json与annotated.avi；可加--no-video只测识别。模板存在、非零时钟及接受观测比例都不是正确率。当前仅适合对比验证，不替代A或C3。

通用数学组件src/modular_agent/realtime/trajectory_bank.py；领域识别器domains/hololive_dreams/models/jump_rope_phase_gear.py。初步测试覆盖正反向丢失首帧续推、挡位下限/上限、非边界不生成后继、低空端点时钟推进、微调不能抵消推进、单帧不切换以及输入保护。


## 当前离线结果与限制

386项测试通过。C2前200帧的曲线、阶段输出与有效标志和修改前保存结果完全相同。4010帧模型时钟全为正，普通旋转近零速度0帧，所有挡位边界约束满足；2258个保持同一假设、没有候选校正的播放帧相位与上帧状态的时间推进完全相等。数学转折测试验证低空端点速度为零、加速度非零、下一帧自然反向。constraint-report.json记录详情。

这不代表视觉成功。当前接受视觉支持1204/4010帧，14/20/32/55秒可见点中位误差约6.14/6.32/31.18/38.58像素；C3相应约10.55/5.90/9.27/13.39。32秒甚至出现错误曲线仍有局部支持的情况，明确是识别失败。回放共选择约60次模式变化，包含错误状态竞争，不能解释为真实游戏技能次数。当前挡位/边界/模板并未校准，整段精度尚未超过C3，所以C4不能替代旧路线。

CV平均13.19ms、P95 18.14ms，不含采集/预览，实机60FPS尚未确认。annotated.avi是本次最终回放，panel显示clock、挡位、速度范围、投影速度v及模板加速度a。speed-analysis.json记录暂定速度范围来源；不是精准真实挡位标注。

同路径假设替换的阶段差也限制在0.008周期内。不同运动模式确认存在延迟，当前显示预测可能纠正到另一个合法模式的当前位置；它不是游戏瞬移，记录selected_hypothesis、model_selection_count和last_motion_event。不同模式的模板接缝及切换时刻仍需独立标注，不能声称完整轨迹已经连续且准确。
