# 绳段逐帧检阅与标注

打开当前模型逐帧页，刷新以加载新控件。当前显示模板的匹配分数、独立绳子外观检查分数、最高累计分候选的即时分数和累计分数逐帧更新；0–1是内部匹配指标，不是正确概率。“未评估”与低分区分显示。低分/不可信时模型仍可继续预测，符合当前用户指定的显示预测驱动输入试验。

1. 输入帧号或用左右键定位；下一低分帧跳至匹配分数低于0.45的后续帧。“下一分数冲突帧”跳至模型分数至少0.50但外观分数低于0.20的帧。外观检查目前也会漏检，作为对照，不强制改选模板。高分也可能错，请以实际绳子为准。
2. 可以取消“显示预测与识别点”，独立检查真实画面，避免被预测引导。
3. 勾选“标注可见绳点”，沿实际可见绳子点击，尽量覆盖两端及中间弯曲处；顺序不强制，但从左到右更方便。每个清晰片段点5–10个点即可，不点击角色或背景，不补遮挡处。
4. 遮挡帧勾选“本帧有遮挡”，只点当前仍看得见的各段。绳子完全看不见时可只记录遮挡与备注，不造点。
5. 撤销一点/清空本帧只改本次新标注，已有青色人工点保持独立。紫色点属于本次标注。备注和问题标签需要保存本帧反馈；点位/遮挡会自动保存到本浏览器。
6. 导出检阅反馈JSON后交给开发程序。schema=2同时含feedback和frame_points；点坐标是原始全画面归一化x/y，附帧号、时间、录像路径与回放哈希。浏览器本地保存不能替代导出备份。

优先：明显偏离却高分的帧、预测与真实绳子开始分开的前后各几帧、进入/离开遮挡的连续帧。遮挡段可每3–5帧点一次，形态急变时逐帧点；无需整段每帧全标。原始1453/1837反馈已保存为独立来源记录，修正页与原页使用不同回放哈希，不覆盖原反馈。
