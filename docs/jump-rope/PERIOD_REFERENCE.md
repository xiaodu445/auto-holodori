## 如何避免选错

1. 先确认画面计数所属阶段；同一速度可能出现在不同阶段或技能，不要只看快慢。
2. 标签以你能确认的实际技能、声音及连续画面为依据，周期只作交叉检查。声音响起不等于速度已立即变化，切换附近用“切换段”，不要直接归入稳定新档。
3. 普通旋转选择一圈相同绳形、相同方向的两帧，真实时间差用timestamps.json；最好量3–5圈再平均。不依赖截取区间总长度恰好等于整数圈。
4. 低空一次完整周期是一去一回，转向点到另一转向点只算半个周期。上述阶段2/3/4完整往返旧参考约2.40/2.00/1.71秒，半程粗略约1.20/1.00/0.86秒；原时间形状有非匀速，不能据此假设任意两帧之间都匀速。
5. 失误、扣血、遮挡或技能边界附近不要通过计数差直接推断整圈数。不确定时保留片段并写备注，不强行选档。
