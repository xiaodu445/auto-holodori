# 边走边扫描小地图建图

## 修好地图后只做位置追踪

双击minimap_track.cmd，默认选择runtime/patrol/maps下最新完成的repair-map配置；8秒内切回游戏。此入口只定位，目标采集10Hz，不执行图优化、多帧地图重绘或移动输入。光锥方向不明不会整帧否决位置，但相似度、唯一性、覆盖和两帧确认照常；不能把键盘预测显示为观察成功。

追踪预览默认100%原始像素，不压缩或拉伸。拖大/缩小窗口只改变可见范围，滚动条/滚轮查看上下，Shift+滚轮查看左右；退出可关闭窗口或Esc/Q。未确认位置时显示NOT LOCALIZED，不画错误候选位置十字。将预览放到游戏之外后切回游戏，否则焦点/遮挡守卫仍会停止。

日志在runtime/patrol/时间戳/observations.jsonl，包含掩膜处理和定位耗时；summary.json记录实际配置来源。p95算法耗时与截图到显示的延迟不同，不能拿离线计时代替实机帧率。F12/失焦/遮挡/窗口变化/停止文件保持原守卫。

定位以游戏小地图为主要观测。后续WASD时长只能作为经标定的弱运动先验，用于限定搜索或短时辅助，不等同IMU或实际位移；遇墙、键盘吞输入和镜头变化需由视觉反馈纠正。小地图相邻配准与全图匹配并非独立传感器，不能重复计权。

### 后续导航标注需求

定位地图与可通行地图分层：小地图coverage仅表示看见，不表示能走。独立导航层需存地图版本/原点/尺度、已确认可走区域、墙/障碍、禁行及未知区。未知区默认不进入自动路线。跳跃用有方向的起跳—落点动作边，保存适用层级和待验证状态；上下层、桥面或台阶如存在需单独区分。地图几何变化后标注必须检查坐标关系，不能默默沿用错误位置。现有A*二值walk-mask不具备这些完整语义，不声称已经实现跳跃规划或自动避障。

## 去光锥与实时位置校正

`minimap_repair.cmd` 使用原始手拼导出的截图、逐帧掩膜和位置初始化，手拼位置作为软约束。你仍手动走动，8秒内切回游戏；程序不发送游戏输入。原minimap_continue.cmd保持固定参考补洞行为。

修复模式从中心角色标记外侧的近白色尖角估计朝向，逐帧排除前方±58度扇区。不是按黄色过滤地形；缺少清楚方向或有冲突则拒绝入图。保留用户掩膜，圆范围最高0.89；光锥排除同样用于匹配和合成。此为本游戏UI启发式，未保证每种缩放/遮挡均识别成功。

相邻帧建立平移关系；附近已保存的原始帧若通过独立匹配，也加入约束，用稳健加权求解位置。第一张作坐标基准，其余人工位置可小幅移动；任何人工块需移动超过12像素时拒绝该次优化并记录。每次从原截图重绘，不把旧位置的像素残留在新图上，也不做错位均值融合。仅优化平移，不对道路做自由形变；大片相似路面、缺少重访仍可能无法建立约束。

小型高饱和粉/红/绿色圆点配合浅色描边作为随机标记排除，不参与约束或地形合成；这是局部外观过滤，不保证所有图标均覆盖，也不在本阶段补绘彩点。特征不足时，只在已有位置先验附近±6像素尝试直接重叠匹配，需强相关、独立峰值及有效覆盖，不能用它全图猜位置。

画面中的圆形细纹并不都位于前向扇区，因此位置校正后还做多观测颜色共识：至少3个关键帧有效观测的像素，选择最接近逐通道中位数的真实观测颜色，不混合成模糊边缘；观测不足保留单源并单独标识。实时合成约每3秒刷新，退出前完整重绘；不保证静止转向、相同半径重复观测或长期不变覆盖可被移除。多次观测一致不等于地理真值，需要最终看图复核。

会话目录另外保存repair-map.png、repair-map-transparent.png、repair-coverage.png、changed-pixels.png、pose-graph.json、latest-clean-mask.png和patrol-config.json。repair-map是待审核版本，黑/透明区域是仍缺乏干净观测；新图不回写原手拼项目。匹配最多600关键帧、原有帧/时长预算照常；F12/失焦/遮挡/窗口变化停止，先保存再退出。

multi-view-coverage.png白色区域有至少三帧参与颜色共识，黑色不一定是未覆盖，也可能只有单/双帧。没有将多帧支持数表述为独立地面测量次数。

经过待修接缝时宜从不同方向重复经过，并走回已有地标区域，让多次观测约束同一位置。采集结束按新旧接缝检查，不将接纳数或边残差视为全图真实精度。

可离线重用现有录像，无需为本轮验证重新跑图：`tools/replay_minimap_repair.py 录制目录 --reference-config 原手拼导出/patrol-config.json --output 新目录 --stride 2`。输出附带遮罩诊断和重放报告，不发送输入。

## 用手拼底图在实机续采

双击 `minimap_continue.cmd`，8秒内切回游戏，在已拼好的区域开始手动走动。此入口固定使用用户20261025-171509手拼导出，不使用离线补洞的manual-refined图。预览窗口放在游戏之外；失焦/F12停止后重新启动会另建会话。

每帧先对照固定参考定位，两帧确认后核对重叠像素。有效位置写入新会话frames.jsonl，原始截图保存在tiles。橙色轮廓仅表示未审核候选；candidate-overlay.png是透明候选层，preview.png为带轨迹的检查图，reference.png保留原底图。候选不写入定位参考或最终地图；光锥仍可能污染候选，后续需在掩膜编辑器检查。靠近缺口应保持至少60%有效区域与原参考重叠；失配时回到已知区域，不按猜测位置续拼。这一版不会扩大原参考画布或自动控制角色。

可指定其他人工导出配置：`minimap_scan.cmd --reference-config "导出目录/patrol-config.json"`。当前不与--resume/--auto-walk组合。定位使用参考PNG像素坐标，不直接沿用原录制世界原点。沿用minimap_mapping=passive策略，无菜单交互或游戏输入。

已有扫描结果可用 `minimap_align.cmd` 进行[半自动地标/像素对齐](minimap-alignment.md)，不需要重跑；人工修正另存并约束整段轨迹，再导出新图。

## 两个入口

双击 `minimap_scan.cmd`：8秒准备后，你手动走动，程序只读小地图并拼图。首次建议用这个模式走一小圈、回到出发点，检查拼接是否对齐。

双击 `minimap_explore.cmd`：显式启用 WASD 自动探索。先分别发送 W/A/S/D 各0.3秒，依据小地图实测位移建立四方向标定；卡住或四键方向不足以覆盖平面则停止。标定通过后以最多0.15秒的单键短步探向未覆盖边缘，再重新截图验证位移。此入口实际发送移动输入，没有点击菜单或自动拾取。

运行前进入自由场景，固定镜头，把预览窗口移到游戏外，在倒计时内切回游戏。F12、失焦、遮挡、窗口移动缩放、Ctrl+C、关闭预览或停止文件停止；自动模式定位失败立刻停止。按住方向或转镜头可能改变标定，自动模式运行期间不要同时人工控制；需要介入时先F12。

```bat
rem 手动走动建图，默认20分钟/3000帧/4096像素边长预算
minimap_scan.cmd

rem 自动探索，默认最多500次探索短步，另有四次初始标定输入
minimap_explore.cmd

rem 显式限制试运行时间和动作数
minimap_explore.cmd --duration 60 --max-actions 30

rem 不显示预览，避免单显示器上窗口挡住游戏
minimap_scan.cmd --no-preview

rem 继续旧底图，但创建新的输出目录；角色先回到旧地图末尾附近
minimap_scan.cmd --resume runtime/patrol/maps/旧目录

rem 使用已确认且同一镜头下的四方向向量，跳过四次探测
minimap_scan.cmd --auto-walk --motion-calibration path/to/motion-calibration.json

rem 离线重放客户区视频，或按文件名排序的原始小地图PNG
minimap_scan.cmd --video path/to/screen.avi --stride 6
minimap_scan.cmd --tiles path/to/tiles
```

`--config` 只读取已有配置的小地图 ROI，不读取其中 reference 图。无需准备完整地图。`--decorated` 仅用于离线包含38像素标题栏的这批样图布局。原始小地图方块大小变化会停止接纳，避免窗口缩放后悄悄错拼。

## 保存的内容

`runtime/patrol/maps/时间戳/` 每15秒及退出时保存：

- `map.png`：累计观测的纯地图，未知区域黑色。
- `map-transparent.png`：未知区域透明的地图。
- `coverage.png`：白色为已观测有效像素；这不是可通行遮罩。
- `preview.png`：带已走轨迹和当前位置的预览。
- `mapping.json`：地图原点、轨迹、接纳/拒绝数及停止前状态。
- `state.npz`：可续扫的地图、权重及近期关键帧；不使用pickle。
- `tiles/`、`frames.jsonl`：原始小地图截图与逐帧匹配证据，可离线重新拼接。截图含中心角色标记，拼接时有固定中心遮罩。
- `patrol-config.json`：可交给上一版巡逻定位预览使用，保留未知区覆盖约束及小地图归一化尺寸。
- 自动模式额外保存输入审计、四方向标定与实际采样记录。

```bat
patrol.cmd preview --config runtime/patrol/maps/本次目录/patrol-config.json
patrol.cmd edit-route --config runtime/patrol/maps/本次目录/patrol-config.json --route runtime/patrol/maps/本次目录/route.json
```

地图坐标为归一化后小地图像素，初始角色位置为(0,0)，北向不变；PNG坐标需减去 `origin_world_xy`。初版地图可增大、向负坐标扩展，不能把截图边界当游戏边界。

## 拼接和探索方法

相邻地图使用双向稀疏光流及独立特征匹配，再做RANSAC、位移上限、空间分布、旋转/缩放、有效重叠、颜色相关与强重复平移检查。特征不足或匹配不可信时不写图、不累加猜测坐标。手动模式可回到最后可靠区域重新匹配，关键帧恢复也要求位置一致。

只遮掉圆形边界和角色中心。因为底图来自相同的小地图，固定设施图标可以作为地标，不再像对照大地图时那样将全部青色图标和河流擦掉。未知处要等其他位置真正看到后再填充。角色图标之外的动态标记仍可能污染局部，当前没有逐类动态图标识别。

自动探索优先朝小地图未覆盖的边缘走；无位移则在当前局部格记录失败方向，换方向尝试。附近没有可试方向时，尝试沿已实际经过的轨迹回溯到更早的未覆盖分支；回溯也无位移或预算耗尽则停止并保留地图。只控制 WASD，不转镜头、不跳跃、不使用 E、不猜测可走道路。

## 当前边界

这是初版自动探索器，不能保证一次扫完整个世界：三维障碍、台阶、门、重复地形及动态标记可能需要人工绕行。覆盖率的分母（整个世界边界）未知，因此只报告已观测像素，不伪造全图百分比或“扫描完成”。没有完整位姿图优化，长路线可能积累漂移，应常回到已扫区域核对；地图错位可根据原始tiles离线重放调整。

自由场景守卫目前为小地图有效证据配合固定跳跃HUD；它不是完整弹窗分类器。某些保留背景HUD的弹层可能仍通过外观检查，自动模式会在无地图位移的有限探测后停止。自动标定假设短时间内镜头固定，未验证跨视角/自动回正；不成功就停止，不套用默认北向WASD。

测试采用合成地形、裁剪平移、保存/恢复和用户提供的静态HUD样图；尚未在真实游戏中自动探索，也没有据此声称得到真实全图。`tools/minimap_mapping_demo.py` 使用用户提供的图三做离线裁块模拟，明确不是实机小地图录像。

本轮建图/探索新增27项测试；上一版巡逻40项、公共交互22项回归通过。建图测试包括未知场景自动模式零输入、手动模式不创建输入后端的主循环测试，以及重复纹理、回到起点、角色中心遮罩、失配不写图、缩放/旋转拒绝、预算、恢复和死路轨迹回溯。101张离线重叠裁块模拟及CLI重放均接纳101帧，定位误差最大约0.002像素，仅证明理想裁块条件下的拼接；结果在 `runtime/patrol/mapping-demo/`。真实连续小地图存在动画和渲染差异，不适用该精度数字。
