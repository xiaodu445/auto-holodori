# 小地图半自动对齐工具

## 从零手工拼一张

双击 `minimap_manual.cmd`，或在编辑器里点“从零新建”。这会创建单独的新项目：空白画布、0帧已加入，原来的自动坐标全部不采用，原项目和旧地图保留。每次使用这个入口都是新建；继续旧手工拼图请使用“打开拼图项目…”选择此前保存的 `alignment-project.json`，或通过 `--project` 打开它。

1. 左侧挑一张清楚的截图，在“素材掩膜”页画好掩膜，点“确认加入 B”。它会作为一张独立图片加入“自由拼图画布”。
2. 在画布上左键选中、拖动任意图片，或用方向键微调；第一张也可以随意移动。每张图的位置独立，不会牵动其他图片，不需要先配对A/B或标地标。
3. 继续挑下一张、画掩膜、加入、摆放。后加入的图显示在上方，被掩膜排除的区域透明，露出下层图片；可用B置顶/置底调整覆盖关系。取消“B参与合成”可以移除截图，允许移除到空白状态。
4. 重建导出时只合成已确认的帧，不混入其他自动接纳帧。导出和原图都另存；新模式不自动保证亮度连续，原图的光效仍需要掩膜处理。

每张新增图初始放在(0,0)，由你自己摆放；手工模式不使用自动坐标、轨迹平滑、固定原点或后续自动吸附。“用地标对齐B”是可选的一次性辅助，只将B放到匹配位置，之后自由拖动不会受旧地标约束；残差仅供对照。手工合成按图层顺序覆盖有效像素，不自动按亮度或暖黄程度挑选其他帧的颜色。

较早的手工项目会先计算并保留原来摆放的位置，再转为独立图层；保存前留一份 `alignment-project.before-free.json` 备份。自动底图校正模式仍使用原来的轨迹约束，不受自由拼图改动影响。

命令行也可使用 `minimap_align.cmd --from-zero`。原入口 `minimap_align.cmd` 仍保留自动底图校正模式；“选择扫描记录”用于选择素材源，“打开拼图项目”用于恢复已经保存的手工进度。

## 自动底图校正模式

入口：双击 `minimap_align.cmd`。默认打开最近一份原始扫描记录，并按全部时间戳核对、优先使用兼容的重建位置；当前这份记录将使用修正后的v3轨迹。工具完全离线，不截图、不发送游戏输入，不修改原始截图或旧地图。

## 推荐操作

1. 左侧先选有明显重影的关键帧，作为待调整的 **B**。默认最多列出180张关键帧；勾选“显示所有原始帧”可选择任何一帧，包括原来匹配失败的帧。
2. 点“推荐重叠A”，寻找位置接近、时间不同的参考帧；也可以双击左侧任意帧设为 **A**，或在帧号输入框直接指定。选择两张能看到相同道路交点、建筑角点的帧。
3. 在 A、B 上分别左键点同一处固定地标，点“加入这组地标对应”。程序把这条约束用于整段轨迹的平滑修正。参考位置已经核对可靠时，可先点“固定参考A位置”。
4. 切换“透明叠加 / 闪烁对比 / 差分增强”检查重合。也可在叠加图中左键拖动 B，或用箭头按钮微调；步长有0.25、1、5像素。先点击画布获得焦点后，键盘方向键也可微调。
5. “重建并导出地图”在新目录合成全部参与帧，自动切换到地图总览。原先的底图总览不会随着每次微调实时重拼，导出后才刷新。

滚轮缩放，右键拖动平移，“适应窗口”恢复。地标应选有效地形内的固定结构，避开中心角色、NPC、边框、黄色扫描纹和会变化的图标。用几处分散的地标比在一个小图标上反复点更有效。

## 手动掩膜：去掉锥形黄光，扩大可用圆

掩膜工具在A/B原图上使用，紫色覆盖表示被排除的像素；叠加图和最终导出都不使用这些像素。它只决定哪些原始像素参与拼接，不会填补或重绘被遮住的地形，缺失位置需由其他观察帧补足。

1. 将“外圆半径”从默认约64像素增大，或点“外圆扩到90%”（164方块对应73.8像素），再沿红色装饰圈内侧调整。最大可设82像素，但截图外的内容无法恢复，扩到边缘也可能包含装饰。
2. 选“多边形擦除”，在黄光锥形区域外沿逐点点击，按Enter、双击或点“完成多边形”闭合。它也适合圈掉角色光效和不规则动态图标。
3. 用“画笔擦除”拖动补细节，“画笔恢复”恢复误涂处。笔刷半径以原始归一化小地图像素计，缩放画面不改变笔刷实际尺寸。Ctrl+Z可撤销；绘制中的多边形Ctrl+Z删除最后一个顶点，Esc取消未提交绘制。
4. 方向固定的遮挡可选“全部帧通用”；锥形光随方向改变时选“仅当前帧”，即你正在画的A或B那一帧。“复制B掩膜到A”仅复制B的逐帧绘制，圆范围和通用掩膜仍由全局设置决定。

通用掩膜先应用，逐帧绘制再应用，因此某帧可以恢复通用掩膜误删的地形。恢复笔刷不能突破外圆或中心保护区；要扩大地形范围，应先修改圆半径。中心遮挡半径也可调整，设为0表示不遮挡中心，但角色可能因此写入地图。圆范围对全部帧生效。

支持导入/导出164×164黑白PNG：白色保留、黑色排除，导入会替换所选范围的绘制；仍受当前圆边界限制。旧人工地标若后来被掩膜遮住，界面会显示数量提示，原约束保留，需自行核对或删除。新增地标不能选在被排除区域。

掩膜随修正项目自动保存、恢复、撤销。导出另含 `global-input-mask.png` 和逐帧PNG；`patrol-config.json` 会携带通用掩膜，后续定位也使用通用有效区域。逐帧掩膜只用于这批离线帧的合成，不能自动推断未来画面的锥形方向。扫描器原来的保守默认半径不随编辑器修改。

## 保存、撤销与冲突

每次修改自动保存；Ctrl+S手动保存，Ctrl+Z或“撤销”最多回退40步。自动底图模式中，有约束的帧需先删除相关约束才能排除，首个参与帧固定为坐标基准；自由拼图模式每张图均可独立移动、移除和调整图层顺序。

残差表示地标校正后仍相差多少像素；超过1.5像素显示提示色。它可能来自点错位置、图标变化或约束互相冲突，程序不会把最小二乘求解成功当作地图已经准确。固定位置和地标是高权重约束，并非绝对硬约束；不一致的约束会留下可见残差。

约束项目保存在 `runtime/patrol/alignments/记录名-轨迹摘要/alignment-project.json`，通过原始记录和位置日志SHA256核对归属。再次打开相同记录/轨迹时自动恢复。切换到另一版位置日志会使用不同项目，避免把旧修正无声套到另一条轨迹。

每次导出位于项目目录下 `exports/时间戳/`，包含：

- 地图PNG、透明地图、覆盖遮罩、预览、续扫状态及 `patrol-config.json`。
- `alignment.json`：此次使用的人工约束副本。
- `corrected-placements.json`：每个参与帧修正后的浮点坐标。
- `export-status.json`：完成/取消状态、地标残差和最大修正量。未完成的导出不会标为完成。

导出可以取消，关闭窗口时也会先取消正在进行的导出。原记录始终保留。0.25像素修正会保留在坐标中，并在导出时做亚像素采样，不会简单四舍五入丢掉。

## 实现与验证边界

稀疏平移图将相邻帧的自动位移作为原始形状约束，把人工固定位置、跨时间的同一地标作为额外约束，用预条件共轭梯度求解轨迹修正，不依赖SciPy。中间帧沿时间平滑分配修正；这是人工辅助回环约束，不是自动发现回环。移动帧自身不旋转、不缩放，适用于当前北向固定的小地图。

动态覆盖使用人工有效掩膜和建图器的暖黄覆盖筛选；手动几何对齐无法保证每个动态图标都无重影。现有画笔、多边形和黑白PNG掩膜编辑，不自动识别每类动态图标，也不自动认定全图准确/世界探索完成。

离线测试覆盖轨迹平滑分配、跨帧地标纠偏、冲突残差、固定原点、遮罩外地标拒绝、撤销/重开、记录哈希拒绝、排除帧、亚像素导出、取消和源文件不修改。原始1182帧记录已完成原生窗口创建与渲染检查；未代替用户添加真实人工地标，不将测试中的合成约束保存到用户工作项目。

26项核心测试通过，覆盖新增全局/逐帧掩膜、恢复优先级、扩大有效圆、PNG导入、保存撤销、被掩膜地标、导出覆盖和定位输入掩膜；另有隐藏Tk窗口中的地标、拖动、画笔、多边形、扩圆及保存事件验证。原始记录中932个有效位置的全量无人工修正导出已通过，测试输出在 `runtime/patrol/alignments/verification-unedited-20261025/`，仅验证导出链路，不代表地图得到人工校准。29项建图、40项巡逻、22项交互协议回归通过。
