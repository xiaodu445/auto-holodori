# 厨房颜色搜索

双击 kitchen_color.cmd：打开最新录像的本地校准窗口，不操作游戏。
1. 类别框输入英文ID，例如 milk_carton。
2. 在容器内拖框，采集框内平均颜色；单击则采集5×5邻域均值。同一类别可在不同物体/帧上采多个色调。
3. 拖动时间轴并松开鼠标查看其他场景。绿色圆点为候选坐标。
4. 添加其他类别；错误采色可撤销。关闭前点击“保存颜色配置”。
5. 运行 kitchen_color.cmd --export，抽24帧导出叠图和candidates.json。

配置保存 runtime/kitchen/color-profile.json；无预置类别，需先采色。
每类可修改 tolerance（OpenCV HSV：H 0..179，S/V 0..255）、min_area、min_radius。
ROI为客户区归一化[l,t,r,b]，默认针对当前录像容器，其他布局需调整。
重叠颜色类别的共同像素会被排除，避免静默分配类别。
坐标取颜色连通区域距离边界最远点，不使用可能落在孔洞中的质心。
返回 color_margin_px 是几何余量，不是分类概率。

局限：相接物体会合并，同一物体分离露出会产生多个候选；高光、阴影与包装共享颜色
可能漏检或误检。未完成独立实例计数、弹窗/游戏状态识别，不直接生成可执行三消序列。
不会自动点击；导出的候选标记 unverified_color_component。
真实录像人工校准和分类准确率尚未验证。离线合成测试不能代表游戏点击成功率。

## 区域平均颜色

采样与搜索均使用平均颜色：H采用饱和度加权的环形均值，S/V采用算术均值。
搜索默认在原始ROI上计算5×5滑动窗口均值，再与每类各采色样本按HSV容差匹配。
配置average_kernel可调整窗口大小，必须为正奇数；1表示逐像素颜色。
旧配置缺省使用5，新旧样本仍保留；建议重新采集区域均值样本以统一口径。
拖框应选同一物体的代表性表面，避免混入背景与遮挡物；均值窗口会模糊边界，
小于窗口的可见碎片可能漏检，color_margin_px也只是平均色匹配区域的几何余量。
