# W运动与镜头标定

入口 `motion_probe.cmd`；也可在路线标注工具规划后点击“W加速 / 镜头一圈标定工具”，自动带入该地图配置和规划掩膜。打开工具本身不发送输入；选择具体测量后有8秒切回游戏。把预览挪到不遮挡游戏的位置，再让游戏保持前台；F12、失焦、遮挡、窗口改变、关闭预览、停止文件或过期场景均结束，不自动重新探测。

## 镜头一圈

游戏直接移动鼠标转镜头。角色保持原地，不按WASD，不操作鼠标。点击“原地测镜头一圈计数”，独立线程以约240相对计数/秒连续发送，每10ms检查守卫并最多移动4计数，截图和拟合不再插入转动停顿。默认总预算12288计数、时间上限90秒；观察累计超过365度且首尾方向相差不超过12度才提前结束，再以全部原帧复核。可点“反向镜头复测”独立测相反方向。

方向证据来自多个原地截图中变化的黄色光锥：在中心角色和外圈HUD之外，按各地面像素的时间最小/最大暖色变化归一化，未变化区域视为未知，再联合拟合固定宽度扇形的两条边，取几何中线。**不拿暖色重心或人物白色突起当镜头朝向**。橙线为中线，黄线为拟合扇形边界；有歧义则不画方向。图像与方向同帧显示，初期可能未知，预览约0.6秒更新一次；游戏里的转动连续进行。若底图能定位，也显示人物地图坐标；按WASD或可靠位置移动超过3像素会停止原地镜头测量。

成功才输出 `camera-calibration.json`：每计数转角、一圈等效计数、实际观察转角、首尾闭合误差、拟合误差、旋转方向和采样协议。不足一圈或首尾未闭合时只保存 `camera-candidate-incomplete.json`，退出码为失败，设置界面明确“未完成一圈”；候选一圈数只是外推。光锥方向不足、缺帧间断、单步过大或拟合误差高时不输出成功标定。

这不是鼠标硬件DPI。结果是当前游戏灵敏度、系统鼠标设置、SendInput相对移动步长和速度下的**一圈有效程序计数**；改变这些条件应重测。旧分段测试结果不混入新的连续移动标定。镜头测量完成后不会自动恢复原朝向，也不会自动接管寻路。

## W加速及松键滑行

当前默认依次测0.3、0.6、1.2秒，松键后继续记录1.2秒；界面“W时长(秒)”可填写2至4组，单组最长2秒。请在前方有足够长直线空间的平坦场地测试，保持镜头不变。长按中连续约0.25秒没有位置进展会停止，不会因撞墙继续顶满测试时长。

稳定速度由持键期间位置—时间斜率独立测量：多个0.25秒窗口共同覆盖至少0.45秒，窗口速度范围不超过中位数10%，且趋势足够平缓才确认为平台。`speed-measurement.json`保存平台区间与实测地图像素/秒，即使动力学拟合失败也保留。`steady_speed_pixels_per_second`没有平台时为空；模型推算的极限速度放在`model_terminal_speed_pixels_per_second`，不当作实测稳定速度。设置窗口会显示是否观察到平台及速度值。

可以直接走，不必先标地图。将角色放在平坦开阔处，前方留足空间，保持镜头固定，可走PNG留空后点击“测W稳定速度 / 加速 / 松键滑行”。程序仍调用当前地图定位。此模式由人选择测试场地，不推断周围没有墙；定位丢失、场景变化、无位移、超出位移包络或取消仍停止并松键，不盲目继续按W。F12随时停止。有掩膜时仍检查已标可走区域。

如需额外的标注检查，可在路线工具标注真实可走区并规划，使用该导出目录的 `patrol-config.json` 和 `planning-mask.png`。掩膜与底图指纹必须一致。有掩膜时，开始前按180地图像素/秒的速度上界检查四周圆盘；长测需要更大的标注开阔区域。标注不正确或实际游戏速度超出包络仍可能有碰撞，程序并不具备真实墙体传感器。

释放W使用独立计时线程，不等截图识别结束。位置以每次小地图有效观测为准，不用按键时间推算坐标；定位失效、场景不明、无位移、位移超出安全包络、松键后仍在移动时停止，不盲目重复W。

`forward-calibration.json` 使用一阶速度上升/衰减模型，给出地图像素/秒速度、加速时间常数、阻尼时间常数、初始加速度、松键滑行距离、位置误差及实际采样间隔。这是运动响应拟合，不是游戏内部物理参数。持键阶段至少3个有效位置且总样本足够；采样比加速/衰减过程太慢、拟合落在参数边界时 `dynamics_resolved=false`，不能据此断言有某个精确阻尼。

两项测量独立选择。W测量会移动角色，不自动回起点；完成或失败后由人调整位置。标定结果暂不自动改写旧固定镜头WASD寻路参数，后续转镜头+W控制应使用新鲜光锥方向闭环验证。

## 文件与验证边界

每次另存 `runtime/patrol/motion-probes/时间戳`：`summary.json`、原始小地图 `tiles/`、带采集时间的位置及输入事件 `observations.json`、输入审计，以及相应的相机/前进样本。原地图、标注、录像和寻路配置不覆盖。工具结束后设置窗口显示原因和诊断目录，失败详情在同名 `.log`。

CLI：`motion_probe.cmd camera --live --config "当前地图/patrol-config.json"`；直接前进：`motion_probe.cmd forward --live --config "当前地图/patrol-config.json" --open-ground --holds 0.3 0.6 1.2 --coast 1.2`。可选用 `--walk-mask "导出目录/planning-mask.png"` 检查标注。没有显式 `--live` 的实机命令拒绝输入。可用 `--mouse-step -24` 反向；兼容旧参数 `--steps` 与 `--mouse-step` 的乘积现在只限定总计数，不再决定走停节奏。W时长每组最长2秒，松键观察时间可设0.2至2秒。

离线回归使用已知动态光锥、固定人物箭头、静止黄地面、正反转圈、已知加速/阻尼、无位移、低帧率、输入失败、延迟弹层/禁用/取消和慢识别反例。旧分段实机录像已用于复分析：232804会话角度与计数拟合RMS由3.38度降至0.44度，但没有绝对朝向人工真值，且只覆盖约223度，仍是未完成扫描。新连续协议及加速阻尼尚未实机验证；未知保留HUD弹层、复杂光锥形状和不平地形仍需复测。
