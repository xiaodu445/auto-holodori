## 当前必要工作

已有12帧264个类别/点击点，但264个实例都没有真实框。
标准YOLO pose必须同时有实例框和关键点；不以点周围固定方框制造训练标签。
双击项目根目录kitchen_yolo_label.cmd：
1. 默认“补实例框”模式，自动选择右侧第一个缺框实例。
2. 参考绿点，拖框包住该实例的可见范围，包含对应绿点；不猜测被遮挡部分。
3. 成功后显示黄色框并自动选择下一缺框实例。
4. 需要改已画框时先选右侧对应实例再拖框；撤销仍可使用。
5. 当前帧补完后用下一张待标帧切换。已有类别、点击坐标和完整标记保留。

## 导出与训练

补框完成后运行train_kitchen_yolo.cmd；先检查标签，再创建YOLO数据集再训练。
缺框、点击点不在框内、标签未确认或有未知忽略区时拒绝启动，不静默丢弃目标。
prepare.py可独立执行，--check只检查，生成人工目录yolo-readiness.json。
导出裁中央ROI并同步变换框和点，字段为class,cx,cy,w,h,click_x,click_y,2。
选择3帧同局诊断留出集，保证每个类别在训练集中至少有实例；其余9帧训练。
不把同局留出集报告成独立游戏泛化，后续仍需新对局验证。
数据集按标签内容摘要创建目录，保留标签快照、切分、类别顺序与预处理。

默认960输入、batch2、150epochs、AdamW、低学习率、验证早停；旋转±180°、平移、缩放、
水平/垂直翻转及适度HSV扰动，mosaic/mixup关闭。
单点击点kpt_shape=[1,3]、flip_idx=[0]、kpt_oks_sigmas=[0.05]，避免沿用人体17关节点定义。
不自动点击游戏，不替换旧模型。

验证：15项原标注与框字段测试＋3项YOLO转换/切分测试通过；真实录像补框界面隐藏加载通过。
只有模型前向与数据管线合成测试完成；真实厨房YOLO训练需用户补框后才能开始。

## 实时训练进度

train.py自动启动独立Tk进度窗口，每个batch与验证结束后原子写progress.json。
窗口显示轮次、百分比、耗时、粗略剩余时间、训练损失与框/关键点验证指标。
关闭窗口不停止训练。可随时运行项目根目录kitchen_training_progress.cmd重新打开。
latest-run.json指向本次状态文件；失败写error.txt，成功状态包含best.pt路径。
实际轮数可因验证早停小于150。默认BF16（RTX5060支持），避免额外AMP探针下载。

进度IO有5次有界重试，失败不传播到模型训练。支持train.py --resume 路径/last.pt断点续训，保持150轮总预算。
